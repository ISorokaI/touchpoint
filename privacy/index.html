Cliche — политика конфиденциальности

Действует с 16 августа 2026 г.

Cliche — расширение для Gmail, которое вставляет заготовленные шаблоны писем с изменяемыми полями. Ниже описано, какие данные оно обрабатывает и как.

Какие данные хранятся

Все шаблоны, папки и справочники, которые вы создаёте в Cliche (названия, HTML-текст писем, значения полей), хранятся локально в браузере через стандартное расширение-хранилище (chrome.storage.local). Эти данные не отправляются на какой-либо сервер Cliche — у расширения нет собственного бэкенда.

Синхронизация с Google Drive (по желанию)

Если вы включаете синхронизацию, Cliche запрашивает доступ только к узкой области drive.appdata — это скрытая папка данных приложения в вашем Google Drive, недоступная ни в обычном списке файлов, ни другим приложениям. В неё сохраняется один файл со всеми вашими шаблонами и справочниками — для их переноса между браузерами. Cliche не запрашивает доступ к остальным файлам на вашем Drive.

Токен доступа Google хранится локально в браузере и используется только для обращений к вашей папке appDataFolder. Cliche не передаёт этот токен и содержимое ваших писем и шаблонов никакой третьей стороне.

Доступ к Gmail

Cliche работает как скрипт на странице mail.google.com, чтобы показать панель шаблонов и вставить выбранный шаблон в составляемое письмо. Расширение не читает и не отправляет содержимое ваших писем куда-либо — вставка текста происходит локально, в браузере.

Диагностика

При работе с Google Drive Cliche ведёт короткий локальный журнал последних действий синхронизации (например, «получен токен», «файл загружен») — исключительно для того, чтобы вы могли посмотреть, что пошло не так. В журнал никогда не попадают токены, пароли или содержимое шаблонов. Журнал хранится только в вашем браузере и нигде больше.

Что Cliche не делает

  • Не собирает аналитику и не отслеживает использование.
  • Не показывает рекламу.
  • Не продаёт и не передаёт данные пользователей третьим лицам.
  • Не использует данные для целей, не связанных напрямую с работой расширения.

Проверка обновлений

Расширение может по вашему запросу обращаться к публичному API GitHub, чтобы узнать номер последней версии Cliche. При этом запросе не передаются никакие данные о вас или содержимом расширения — только сам факт обращения к публичному списку релизов.

Удаление данных

Удаление расширения из браузера удаляет все локально хранимые данные Cliche. Чтобы удалить данные из Google Drive, откройте страницу разрешений приложений Google и отзовите доступ Cliche — это удалит и сам файл в appDataFolder.
